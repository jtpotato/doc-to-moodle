# Formatting Guide
*For the question name:*  
::2027\_D2\_Q1::

*Or add letters for subquestions:*  
::2027\_D3\_Q1a::  
::2027\_D3\_Q1b::

*Drop down:*  
::2027\_dropdown::  
// An image of rocks A, B, C. Use // in front of any line that shouldn’t go through the parser.  
Rank the following rocks in the correct order:

\[Answers\]  
Least porous \-\> C  
Middle \-\> A  
Most porous \-\> B

*Multiple choice (single answer):*  
::2027\_multichoice\_a::  
Who is the best fish?

\[Answers\]  
Jeff (\*)  
Geoff  
Greg

*Multiple choice (multiple answers): (can have different scores for each answer. or don't include a score and let the program distribute the remaining marks evenly)*  
::2027\_multichoice\_b::  
Who are the Program Directors?

\[Answers\]  
Jeff  
Greg (\*) (75%)  
Leslie (\*)
